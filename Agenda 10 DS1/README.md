📝 Sobre o Projeto

Este projeto consiste num sistema de avaliação escolar modularizado. O foco principal desta atividade é o uso de Funções (def) em Python para manter o código organizado, limpo e reutilizável.

🚀 Funcionalidades e Estrutura

O programa foi dividido em três funções principais:

calcular_media(nota1, nota2, nota3): Recebe três notas, calcula e devolve a média aritmética.

verificar_situacao(media): Avalia a média. Devolve "Aprovado" se for maior ou igual a 6.0, caso contrário, "Reprovado".

gerar_relatorio(nome_aluno, nota1, nota2, nota3): Função coordenadora que chama as funções anteriores e imprime um boletim formatado no terminal com todas as informações.

💻 Tecnologias Utilizadas

Python 3

Funções, Parâmetros e Retorno (def, return)

Modularização de código.
