🍃 Classificador de Emissões de Veículos - Agenda 7

📝 Sobre o Projeto

Este projeto em Python tem como objetivo classificar o impacto ambiental de diferentes tipos de veículos com base na distância percorrida mensalmente. É uma ótima prática para aplicar operadores lógicos em estruturas de decisão.

🚀 Funcionalidades

O programa solicita ao utilizador o tipo de veículo (carro, moto ou elétrico) e a quantidade de quilómetros percorridos por mês.

Avalia as emissões usando operadores lógicos (and, or):

Veículos Elétricos: Classificados automaticamente como "Emissão zero! Sustentabilidade total."

Motos (menos de 1000km): Classificadas como "Emissão baixa - uso leve e eficiente."

Motos (até 2500km) ou Carros (até 2500km): Classificados como "Emissão moderada - dentro da média urbana."

Outros casos: Classificados como "Emissão alta - avalie alternativas mais ecológicas."

💻 Tecnologias Utilizadas

Python 3

Operadores Lógicos (and, or) e Relacionais (==, <=, <).
