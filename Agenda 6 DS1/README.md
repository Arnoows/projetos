💰 Sistema de Desconto - Agenda 6

📝 Sobre o Projeto

Este é um programa simples desenvolvido em Python que simula um sistema de caixa registadora com aplicação de descontos automáticos. O programa lê o valor total de uma compra e calcula o desconto com base no montante gasto.

🚀 Funcionalidades

Recebe o valor total da compra do utilizador.

Aplica uma estrutura condicional (if, elif) para definir a taxa de desconto:

Compras abaixo de R$ 200: 5% de desconto.

Compras entre R$ 200 e R$ 299.99: 10% de desconto.

Compras a partir de R$ 300: 15% de desconto.

Imprime no terminal o valor do desconto calculado, formatado para duas casas decimais.

💻 Tecnologias Utilizadas

Python 3

Estruturas de decisão (if/elif/else)

Operadores matemáticos e de formatação de strings (f-strings).
