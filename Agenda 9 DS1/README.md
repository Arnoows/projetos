📋 Gerenciador de Tarefas e Rotina - Agenda 9

📝 Sobre o Projeto

Uma aplicação de terminal desenvolvida em Python para registar tarefas diárias e analisar a carga da rotina do utilizador. Este projeto introduz o uso de listas (arrays) e laços de repetição (loops).

🚀 Funcionalidades

Coleta o nome e a cidade do utilizador.

Pergunta a quantidade de tarefas a serem cadastradas.

Utiliza um laço for para recolher e armazenar cada tarefa numa lista.

Exibe todas as tarefas cadastradas de forma organizada.

Analisa a extensão da lista (len) para determinar a intensidade da rotina:

Nenhuma tarefa: "Nenhuma tarefa cadastrada."

Até 3 tarefas: "Rotina leve hoje!"

Mais de 3 tarefas: "Rotina cheia! Organize prioridades."

💻 Tecnologias Utilizadas

Python 3

Estruturas de repetição (for, range())

Manipulação de Listas (append(), len())
