# Monitoramento de Reservatório de Água 💧

Atividade desenvolvida para a Agenda 11 da disciplina de Desenvolvimento de Sistemas I. O projeto é um simulador executado no terminal que exibe alertas visuais sobre o nível de água de um reservatório.

## 🚀 Funcionalidades
* **Simulação de níveis:** O sistema avalia 5 níveis de capacidade (de "Muito baixo" a "Muito alto").
* **Alertas visuais:** Utiliza a biblioteca `colorama` para colorir as mensagens no terminal de acordo com a gravidade da situação (Vermelho, Amarelo, Verde, Ciano e Azul).
* **Automação:** Usa um laço de repetição (`for`) para percorrer uma lista de mensagens e testar todos os níveis automaticamente, limpando a formatação após cada linha.

## 🛠️ Tecnologias Utilizadas
* Python
* Biblioteca `colorama`
