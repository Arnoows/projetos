# Pesquisa de Satisfação - TudoWeb

Sistema em Python desenvolvido para automatizar a coleta e a contagem de avaliações de clientes para a agência de marketing TudoWeb. O projeto aplica conceitos de estruturas de repetição e de decisão.

## 📋 Funcionalidades
- Coleta o nome, idade e a nota de satisfação do entrevistado (1 - Excelente, 2 - Bom, 3 - Ruim).
- Utiliza o laço `for` para repetir a entrevista exatamente 50 vezes de forma automatizada.
- Conta e armazena os votos de forma isolada utilizando variáveis de incremento.
- Exibe, ao final da execução do ciclo, o relatório total de avaliações "Excelente" e "Ruim".

## 🚀 Tecnologias e Lógicas Utilizadas
- **Linguagem:** Python
- **Estrutura de Repetição:** `for` e `range()`
- **Estruturas de Decisão:** `if` e `elif`
- **Tipagem de Dados:** Conversão de entradas de texto para números inteiros com `int(input())`
