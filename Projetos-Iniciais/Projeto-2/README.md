⚡ Calculadora de Consumo de Energia - Projeto 2

📝 Sobre o Projeto

Este é o consumo-de-energia.py, um projeto prático desenvolvido em Python criado para treinar e consolidar o ciclo fundamental da programação: Entrada ➔ Processamento ➔ Saída. O programa calcula o gasto energético mensal de um aparelho doméstico com base no seu uso diário.

🚀 Funcionalidades

Entrada: Solicita ao utilizador o nome do aparelho (ex: geladeira, televisão), a sua potência em Watts (W) e o tempo de uso diário em horas.

Processamento: Calcula o consumo mensal em kWh utilizando a fórmula matemática:
Consumo Mensal = (Potência * Tempo Diário * 30 dias) / 1000

Saída: Exibe o resultado final no terminal de forma clara, utilizando f-strings para formatar o valor com duas casas decimais.

💻 Tecnologias Utilizadas

Python 3

Funções de entrada e saída (input, print)

Tipagem de variáveis (float)

Operadores aritméticos.
