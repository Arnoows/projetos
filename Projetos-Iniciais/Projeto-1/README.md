📚 Calculadora de Média - Projetos Iniciais

📝 Sobre o Projeto

Este é o app.py, um dos meus primeiros projetos em Python! É um script clássico e fundamental para quem está a começar na programação. Consiste numa calculadora simples que avalia a situação escolar de um aluno através da média de duas notas.

🚀 Funcionalidades

Recebe o nome do aluno através de um input de texto.

Recebe duas notas convertidas para números decimais (float).

Processa o cálculo da média dividindo a soma por 2.

Utiliza uma estrutura if/else básica para imprimir no ecrã:

"Situação: Aprovado" (se média >= 6).

"Situação: Reprovado" (se média < 6).

💻 Tecnologias Utilizadas

Python 3

Entrada e Saída de dados (input, print)

Tipagem de dados (float)
