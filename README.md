# 🐍 Agendas de Python - Desenvolvimento de Sistemas

Repositório dedicado às atividades, exercícios e projetos desenvolvidos ao longo do curso Técnico em Desenvolvimento de Sistemas. O foco principal é a aplicação de lógica de programação, estruturação de dados e automação utilizando Python.

## 🗂️ O que você vai encontrar aqui

Este repositório está organizado em pastas separadas para cada agenda da disciplina. Os códigos exploram conceitos como:
* Manipulação de variáveis e estruturas de repetição (`for`, `while`).
* Criação de scripts para cálculos estruturados (como médias escolares e relatórios de desempenho).
* Sistemas interativos via terminal.

## 🚀 Tecnologias Utilizadas

* **Linguagem:** Python
* **Ambiente e Ferramentas:** Visual Studio Code, Git e GitHub
