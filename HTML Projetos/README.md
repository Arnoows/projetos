# Agenda 12 - Meus Sites Favoritos

Projeto desenvolvido para a atividade da **Agenda 12** do curso técnico em Desenvolvimento de Sistemas (ETEC/CPS via EADTec). O objetivo principal é estruturar uma página web simples utilizando conceitos fundamentais de HTML.

## 🛠️ Tecnologias Utilizadas
* **HTML5**: Estruturação semântica com tags de bloco e texto (`<h1>`, `<p>`), imagens com legendas (`<figure>`, `<figcaption>`, `<img>`) e links externos (`<a>` com atributo `target="_blank"`).

## 📌 Sobre o Projeto
O arquivo `Agenda 12 DS1.html` apresenta uma página com a relação de plataformas e serviços acessados frequentemente, incluindo:
* Epic Games
* Gemini
* Twitch
* JW.org
* EAD Tec
